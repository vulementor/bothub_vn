# BotHub.vn · HTML storefront preview

Bản demo HTML/CSS/JS để duyệt giao diện trước khi chuyển sang WordPress/WooCommerce.

- Trang chủ: `index.html`
- Cửa hàng: `cua-hang.html`
- Chi tiết: `muse-ai.html`, `grok-bot.html`, `chatgpt.html`
- Prompt và so sánh: `thu-vien-prompt.html`, `so-sanh.html`

**Lưu ý:** Đây là preview, không nhận thanh toán, không giao tài khoản. Giá Muse AI là mức dự kiến; quyền phân phối chưa được xác minh.

GitHub Pages: triển khai từ root nhánh `main` sau khi bật Pages tại Settings → Pages.
